# Lark 链上文档结论验证

## 总体判断

文档首页的相对排序基本成立：TAC、BIRB、BANK 的前置信号最强，PLAY、SYN
次之，DEXE 不构成强前兆。需要修正的是：这些数据能够验证链上转账异常，不能
单独证明价格操纵、卖出、真实成交或共同控制。

逐文档结果：

- **强支持：**TAC、BIRB、PLAY、M、DEXE、VELVET、H、RIF、TAIKO。
- **部分支持：**BANK、SYN、BEAT、ALLO。
- **当前快照无法完整复现：**B。
- **缺少精确事件日期，无法做窗口复算：**SIREN、RAVE。

## 数据覆盖与限制

- 新快照捕获时间：2026-07-29 10:06:11 UTC。
- 覆盖 16 个 Token、33 个链上目标，无 token 跳过，共 7,281 个带 SHA-256
  的产物，约 675 MB。
- manifest 状态为 `partial_success`：67 个普通成员 transfer 请求失败，
  另有 2 条关系在 subgraph 与最终组装之间新增了 transfer，触发
  `TransferSnapshotDrift`。
- 按关系图推算约有 3,625 个普通成员，生成了 3,557 个 clean transfer 文件，
  成员文件覆盖率约 98.1%。
- 当前 cluster 是 2026-07-29 的截面，而文档主要使用 2026-07-27 截面。
  两天间 cluster 成员变化会令历史转账覆盖集合改变。因此数字偏差既可能来自
  失败成员，也可能来自后见式成员集合变化，不能直接解释成原文计算错误。
- 所有 amount 均为 gross transfer amount，同一批 Token 来回转移会重复累计。

## 可采信的最终结论

1. **TAC 和 BIRB 的核心数字证据最稳。**TAC 的关键枢纽净流向、BIRB 的
   6/29 批量网络指标均精确复现。
2. **BANK 仍是强异常，但精确倍率应写成“约 35–42 倍，取决于快照成员集合”，**
   不宜只保留 42.15x 单点值。
3. **PLAY 与 VELVET 的异常主要由少数大额迁移解释。**这支持高监测优先级，
   同时削弱“广泛市场资金同步放大”或“操盘”的归因。
4. **DEXE、M、H、RIF、TAIKO 的低/弱判断有数据支持。**
5. **任何操盘、卖出或价格因果结论仍需补价格、swap、池储备、CEX 成交和
   Supernode 历史。**当前数据只能确认 Token transfer 的时间、路径和规模。
