# V2失败交易共性研究

## 样本与原则

- 主样本为逐币独立资金中已完成退出的435笔交易：盈利128笔、失败307笔；剔除截止估值交易。
- 所有特征只使用信号日收盘前已知数据；不使用退出后信息。
- CEX流量与成交量均转成基础币数量；1000前缀合约的成交量已乘1000校正。
- 以下筛选表现属于探索性全样本结果，不等同独立样本外证明。

## 三个核心假设的分位数检验

- **F7c/Cluster**：最低四分位胜率30.28%、均值0.30%；最高四分位胜率32.11%、均值0.09%。
- **7日CEX净流入/此前20日中位成交量**：最低四分位胜率29.36%、均值-1.34%；最高四分位胜率29.36%、均值-2.45%。
- **信号前7日涨幅**：最低四分位胜率31.19%、均值-4.41%；最高四分位胜率23.85%、均值-2.19%。
- **近7日最高涨幅**：最低四分位胜率30.28%、均值-2.68%；最高四分位胜率25.69%、均值-2.03%。

## 失败交易的阈值画像

- **信号日放量超过日常量1.5倍**：158笔，胜率21.52%、单笔均值-4.81%。这是最清晰且在独立样本与共享三仓实际成交中方向一致的失败共性。
- **7日流入超过日常量10%**：73笔，胜率21.92%、单笔均值-8.46%；超过25%时更差。大额流入更像交易所入金后的卖压，不支持“流入越大越好”。
- **信号前7日已上涨超过50%**：17笔，胜率17.65%、单笔均值-9.31%。但样本较少，普通程度的前期异动只有弱效应。
- **F7c/Cluster本身不是有效单变量阈值**：盈利与失败中位数均约0.21%，AUC接近0.5；不能仅因没过某个F7c阈值就判定会失败。
- **流入/信号日成交量偏低**与失败有轻度关系：盈利中位数1.95%、失败1.35%，但置信区间跨零，只能作为辅助特征。

- 4月是唯一整体盈利月份；5月至7月基准胜率降至17.68%、单笔均值-6.66%。
- 全样本看似最好的筛选规则在5月至7月全部转负，说明结果主要受市场状态驱动，不是稳定的样本外过滤器。
- 因此当前证据适合用于构建模型特征和走前验证，不适合直接删除币种；至少应采用按月滚动训练、下一月验证，并显式加入市场广度/趋势状态。

## 初步判断

- 基准单笔均值-2.08%、胜率29.43%。
- 保留至少60笔的简单条件中，均值最高的是“7日流入/日常量介于5%和10%”：保留60笔，胜率38.33%、单笔均值5.85%。
- 但该优势集中在4月，5月至7月没有延续；不能当作已验证收益改进。
- 建议优先建模三个交互特征：信号日放量倍数、流入/信号日成交量、前7日涨幅，并加入市场广度状态；在严格走前通过前，不建议直接删除币种或上线硬阈值。
