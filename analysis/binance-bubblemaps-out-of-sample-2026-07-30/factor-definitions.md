# 六个链上因子定义

## 统一时间窗口

- 事件日记为 `D`。
- 事件前观察窗 `W-1`：`D-7` 至 `D-1`。
- 基线窗：`D-35` 至 `D-8`，拆分为四个自然周。
- 金额均为 Bubblemaps transfers 中的 gross transfer amount，不等同于成交量、买入金额或新增资金。
- Cluster 和成员集合采用 Bubblemaps 抓取日截面。

## 因子定义

| 编号 | 因子名称 | 连续因子值 |
|---|---|---|
| F1 | 转账金额放大因子 | `W-1总转账金额 ÷ 基线四周的周均转账金额` |
| F2 | 转账笔数放大因子 | `W-1转账笔数 ÷ 基线四周的周均转账笔数` |
| F3 | 活跃地址扩张因子 | `W-1活跃地址数 ÷ 基线四周的周均活跃地址数` |
| F4 | 新地址扩张因子 | `W-1首次可见地址数 ÷ 基线四周的周均首次可见地址数` |
| F5 | 巨额转账因子 | `W-1最大单笔 ÷ 基线各周最大单笔的中位数`；同时记录该笔占当前 Cluster 合计余额的比例 |
| F6 | Cluster净流冲击因子 | `W-1对外绝对净流 ÷ 基线各周绝对净流的中位数`；同时记录其占当前 Cluster 合计余额的比例 |

当基线为零且 `W-1` 大于零时，因子记为“从零启动”，而不是除零或缺失值。

## F5 巨额转账拆分

单看“大额”难以区分项目内部整理、交易所充值、桥接、解锁或真正的异常资金动作，因此将 F5 拆成以下解释特征。F5a、F5b 仍决定原 F5 是否触发；F5c–F5e、F5g、F5h用于解释和分层。

| 子因子 | 定义 | 当前可算性 | 实时口径 |
|---|---|---|---|
| F5a 相对历史规模 | `W-1 最大单笔 ÷ 基线四周周最大单笔中位数` | 可算 | 只使用 D-1 及以前数据 |
| F5b Cluster 冲击 | `W-1 最大单笔 ÷ 当前 Cluster 合计余额` | 可算 | 分母是抓取日 Cluster 截面，存在成员集合前视偏差 |
| F5c 内外部属性 | 最大单笔属于同 Cluster 内部、跨 Cluster、Cluster 与外部，或成员范围未识别 | 可算 | 依据当前 Cluster 成员集合 |
| F5d 流向 | 内部调仓、跨 Cluster 转移、外部流入 Cluster、Cluster 流出或未知 | 可算 | 依据最大单笔的 from/to 与成员集合 |
| F5e 对手方类型 | CEX、DEX/LP、Bridge、Staking、Vesting/Lock、多签、其他合约或未知地址 | 部分可算 | 仅在现有 Bubblemaps 地址元数据有标签时识别 |
| F5f 后续路径 | 快速转入交易所、拆分、归集、原路返回等 | 不纳入实时因子 | 只能作为事后标签；完整计算需要持续、多跳、外部地址转账数据 |
| F5g 持续性 | W-1 内巨额转账的笔数、发生天数和最长连续天数 | 可算 | “巨额”逐笔门槛为 F5a ≥ 3x 且 F5b ≥ 0.5% |
| F5h 市场位置 | 前一日放量突破、上涨后高位、下跌中、极低成交量、盘整/普通或历史不足 | 可算 | 只使用 D-1 及以前 K 线，不读取 D 日和未来行情 |

F5g 的离散标签为：

- `无巨额转账`：W-1 没有逐笔同时达到 F5a、F5b 门槛。
- `单日孤立`：只在一个交易日出现。
- `连续多日`：至少两个相邻自然日出现。
- `间歇多日`：多个日期出现，但日期不连续。

F5h 当前规则为：

- 前一日收盘突破此前区间高点，且成交量至少为此前样本中位数的 2 倍：`前一日放量突破`。
- 此前 7 日收益不低于 20%，且距此前 20 日高点不超过 10%：`上涨后高位`。
- 此前 7 日收益不高于 -15%：`下跌中`。
- 前一日成交量位于此前最多 20 日样本的 20% 分位或以下：`极低成交量`。
- 不符合以上条件：`盘整/普通`；历史不足 8 日则为 `历史不足`。

页面逐日数据中，这组拆分存放在每根 K 线的 `f5x` 字段。F5f 会保留明确的未计算状态，避免被误读为缺失值或实时信号。

### F5 子因子高亮规则

| 子因子 | 黄色异常高亮条件 |
|---|---|
| F5a | 相对历史规模 ≥ 3x；或基线为零且观察窗出现转账 |
| F5b | 最大单笔占 Cluster 合计余额 ≥ 0.5% |
| F5c | 完整 F5 命中，且最大单笔为跨 Cluster 或 Cluster 与外部转移 |
| F5d | 完整 F5 命中，且方向为跨 Cluster、外部流入 Cluster 或 Cluster 流出 |
| F5e | 完整 F5 命中，且对手方识别为 CEX、DEX/LP、Bridge、Staking、Vesting/Lock 或多签 |
| F5f | 不高亮；它不是实时因子 |
| F5g | 完整 F5 命中，即存在同时达到 F5a、F5b 门槛的巨额转账 |
| F5h | 完整 F5 命中，且市场状态不是 `盘整/普通` 或 `历史不足` |

这里的“完整 F5 命中”指 F5a 与 F5b 同时满足。F5c–F5h 的高亮用于说明该次巨额转账的结构和环境，不代表额外、独立的买入或卖出信号。

## 当前触发阈值

| 因子 | 触发条件 |
|---|---|
| F1 | 因子值 ≥ 3 |
| F2 | 因子值 ≥ 3 |
| F3 | 因子值 ≥ 2，且 W-1 活跃地址不少于 10 个 |
| F4 | 因子值 ≥ 2，且 W-1 首次可见地址不少于 5 个 |
| F5 | 因子值 ≥ 3，且 W-1 最大单笔占当前 Cluster 合计余额 ≥ 0.5% |
| F6 | 因子值 ≥ 3，且 W-1 绝对净流占当前 Cluster 合计余额 ≥ 1% |

## 因子与模式的关系

- F1–F6 是连续数值，可以用于排序、分层、回测和阈值敏感性分析。
- F5a–F5h 是对 F5 的结构化拆分，不是额外增加七个独立买卖因子。
- “因子触发”是因子值满足当前阈值后的布尔状态。
- 原文异常模式不是单一因子。模式由一个或多个因子，加上转账拓扑、地址标签或跨链关系共同构成。

例如：

- SYN/TAC 总量型主要对应 F1。
- BANK 型通常同时包含 F1 和 F5。
- TAC 枢纽型主要对应 F6，还需要确认净流集中在枢纽地址。
- BIRB 扇出型通常包含 F2、F3、F4，并需要扇出或归集拓扑。
- BEAT 型需要 F2 及固定金额重复结构。
- PLAY/TAIKO 型需要大额活动，并结合 Safe/多签地址标签。
- VELVET 型需要大额活动，并结合 staking、vesting、lock、bridge 或 migration 标签。
- 跨链型需要同一项目在多条链上的时间同步，不能只由 F1–F6 判断。

## 使用限制

- Bubblemaps 当前接口不提供历史 Holder/Cluster 截面；历史转账只覆盖抓取日仍属于当前 Cluster 的普通成员。
- 因子存在幸存者偏差和前视成员集合偏差。
- 因子触发或模式匹配只表示结构相似，不能单独证明操盘、买卖方向或因果关系。
