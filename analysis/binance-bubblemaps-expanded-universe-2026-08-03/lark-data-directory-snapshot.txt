路径口径
当前下载配置以 /data2/shares/raw_tmp 为待校验 raw 根目录；/data2/shares/raw 是校验后的 canonical raw 根目录，/data/shares/raw 只作为旧路径兼容入口。
2026-06-26 及以前的历史分区物理保留在 /data/shares/raw；新日更/月更/普通补数分区先写入 /data2/shares/raw_tmp，校验通过后移动到 /data2/shares/raw。
旧盘历史缺口修复需要显式加 --legacy-raw 或 LEGACY_RAW=1，用于把输出根目录切到 /data/shares/raw；OKX kline 旧 manifest 路径会兼容转换到当前 okx/history/{market}/klines/{quote}/1m 目录结构。
Tardis 待校验落盘根目录是 /data2/shares/raw_tmp/tardis；canonical 根目录是 /data2/shares/raw/tardis。
Binance Vision 待校验落盘根目录是 /data2/shares/raw_tmp/binance/vision；canonical 根目录是 /data2/shares/raw/binance/vision。
Bitget 官方 REST 待校验落盘根目录是 /data2/shares/raw_tmp/bitget/history；canonical 目标根目录是 /data2/shares/raw/bitget/history。
OKX Historical Data 待校验落盘根目录是 /data2/shares/raw_tmp/okx/history；canonical 根目录是 /data2/shares/raw/okx/history。

更新机制
生产环境使用同一个 crontab 统一调度 Tardis、Binance Vision 和 OKX Historical Data，模板见 deploy/cron.example。服务器实际工作目录为 /data2/shares/code/nextalpha-tardis-data，cron 使用北京时间 Asia/Shanghai。Coinbase/Kraken 现货 1m kline 当前仍在历史回补阶段，暂不纳入生产日更调度。
日更任务默认采用最近 2 个完整 UTC 日期的滚动窗口，不包含当天；这样可以覆盖数据源出数延迟，并依赖 skip_existing 跳过已落盘文件。

每次 wrapper 运行会生成独立 manifest，例如 data/manifests/tardis_daily_YYYYMMDDTHHMMSSZ.csv、data/manifests/tardis_daily_kraken_spot_usdt_YYYYMMDDTHHMMSSZ.csv、data/manifests/binance_vision_daily_YYYYMMDDTHHMMSSZ.csv、data/manifests/okx_history_spot_USDT_daily_YYYYMMDDTHHMMSSZ_a1.csv。判断任务是否按时触发，可查看各 wrapper 日志中的 start ... 和 done ... 行；status=0 表示该 wrapper 完成，Tardis 若出现 main_status=0 retry_status=1，表示主下载成功但自动 retry 后仍有 cache job 未生成。
