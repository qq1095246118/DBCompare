# F1–F7 日 K 异动复盘页

打开 `factor-kline-dashboard.html` 即可使用，不需要联网或启动服务。

## 页面范围

- 币种：样本内 SIREN、RAVE、BIRB、VELVET、DEXE；首批样本外 SOON、ESPORTS、KOMA；新增样本外 CYS、BULLA、EVAA、GWEI、CLO。
- 当前总计：13 个币种、60 段 2026 年日线异动、2,669 条逐日 K 线与因子记录。
- 事件：日收盘涨跌绝对值达到 20%；相邻异常日相隔不超过 7 天时合并为一段。
- 全周期视图：从 2026-01-01 或币安合约上市日（取较晚者）起，展示到当前数据截止日。
- 事件视图：选择具体事件后，自动缩放到事件前 42 天至该段最后一个异常日后 14 天。
- 悬停口径：D 日显示的 F1–F7 均只使用 D-7 至 D-1 的链上转账，并与此前 28 天的四个周基线比较。
- F7 CEX净流：`CEX流入 − CEX流出` 为正时表示净流入交易所，为负时表示净流出交易所；异常要求绝对净流相对历史达到 3x 或从零启动，且绝对净流至少占 Cluster 合计余额 0.1%。
- F7覆盖：统计直接 CEX 转账和已确认多跳路径的唯一 CEX 边界交易；路径中间跳不累计，同一边界事件通过链上事件 ID 去重。页面逐日显示直接与多跳笔数。
- F5 拆分：悬停任意日会同时展示 F5a 相对历史规模、F5b Cluster 冲击、F5c 内外部属性、F5d 流向、F5e 对手方类型、F5g 持续性和 F5h 市场位置。
- CEX优先规则：任一端为CEX地址时，F5c/F5d优先标记为CEX相关转账及流入/流出CEX，不再被“同一Cluster内部”覆盖；F5d同时显示此前7日CEX流入、流出和净流。
- 子因子高亮：黄色边框和“异常”徽标表示对应 F5 子因子的高亮条件命中；普通蓝色边框不表示异常。
- F5f 后续路径：只保留“事后路径标签”状态，当前不计入实时信号，以免把转账发生后的信息带回 D 日。
- 缩放操作：图上滚轮围绕鼠标位置缩放；按钮可放大、缩小和全年复位；时间轴滑杆用于左右平移。

## 图上标记

- 蓝色背景：事件前 D-7 至 D-1。
- 红色背景：该段从第一个到最后一个异常日。
- 黄色菱形：至少一个因子达到当前异常阈值。
- 日 K 下方三角：收盘涨跌绝对值达到 20% 的日期。
- 页面下方“七因子详细口径”逐项说明公式、阈值、解释和误读边界。
- 页面右侧“F5 巨额转账拆分”逐日显示最大单笔的结构、流向、标签、持续性和事前市场位置。

## 文件

- `factor-kline-dashboard.html`：自包含交互页，数据、样式和交互均已内嵌。
- `build_dashboard.py`：从现有 Bubblemaps 快照和币安日线重新生成页面。
- `calculate_f5_subfactor_ic.py`：以 F5a–F5h 异常高亮为二元因子，计算 T+N 窗口最大涨幅横截面 Rank IC。
- `f5-subfactor-ic-report.md`：T+1、T+3、T+5、T+7、T+14、T+30 IC 结果与解释。
- `f5-subfactor-forward-ic.csv`：逐因子、逐周期的平均/中位 IC、Newey-West t 值和有效样本数。
- `calculate_f1_f6_ic.py`：同时计算 F1–F6 连续值与异常触发值的 T+N 窗口最大涨幅横截面 Rank IC。
- `f1-f6-ic-report.md`：F1–F6 两种口径的 IC 总表和主要结果。
- `f1-f6-forward-ic.csv`：F1–F6 两种口径、六个前瞻周期的 72 组明细。
- `calculate_cex_flow_ic.py`：把 F7 拆成净流入强度、净流出强度、有符号净流和两个方向异常，计算 T+N 窗口最大涨幅横截面 Rank IC。
- `cex-flow-ic-report.md`：CEX 净流入/净流出在 T+1、T+3、T+5、T+7、T+14、T+30 的 IC 总表和解释。
- `cex-flow-forward-ic.csv`：F7 三个连续方向因子和两个方向异常的逐周期 IC 明细。
- `cex-multihop-boundary-events.csv`：经路径复核确认的 CEX 边界交易；只有 `status=confirmed` 且具备唯一边界事件 ID、日期、方向和金额的记录才进入 F7。
- `../binance-bubblemaps-additional-out-of-sample-2026-07-30/report.md`：5 个新增样本外币的事件与复合信号复核。

页面中的“买入观察”和“卖出风险”来自当前样本阈值校准，只用于复盘提示；同一天同时命中相反阈值时会明确显示“阈值方向冲突”。
